# Тестовое задание MediaSoft.team (Системный аналитик) (КТ2)

**Ссылка на исходное задание:** https://github.com/Hexlet/ru-test-assignments/blob/main/analytics/mediasoft/README.md
**Роль:** Системный аналитик (смежная роль: Тестирование).

## Что это?
Проектирование мобильного клиент-серверного приложения «Список покупок в магазинах». В рамках контрольной точки 2, рассчитанной на 6-8 часов, реализован основной сценарий работы приложения.

## Что не сделано (и почему):
* **UI/UX-прототип экрана:** Исключен для фокуса на технической части (архитектура данных и API).
* **Сложные офлайн-конфликты синхронизации:** Описана базовая логика разрешения конфликтов (Last Write Wins).
* **Вопросы заказчику:** Исходные требования сочтены достаточными для проектирования базового сценария.
